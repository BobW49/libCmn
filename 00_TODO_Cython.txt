To wrap your existing C W32Str object in Cython for use in Python, we'll create a Cython extension that exposes the C structs and functions as Python classes/methods. This allows you to call your C methods from Python while keeping the internals hidden, maintaining your Objective-C-like design.

### Prerequisites
- Compile your C code (e.g., W32Str.c, W32Str_object.c, W32Str_json.c) into a static library (e.g., libw32str.a) using gcc:
  ```bash
  gcc -c -fPIC W32Str.c W32Str_object.c W32Str_json.c -o libw32str.o
  ar rcs libw32str.a libw32str.o
  ```
- Include all necessary headers (e.g., cmn_defs.h, AStr.h, etc.) in your build path.

### Cython Wrapper Code
Create two files: `w32str.pxd` (C declarations) and `w32str.pyx` (Python wrapper).

#### w32str.pyx (Python Wrapper)
This wraps the C object in a Python class, simulating your Objective-C style with methods.

```cython
# distutils: language = c
# cython: language_level=3

cimport w32str  # Import the .pxd declarations

cdef class LexJ:
    cdef w32str.W32STR_DATA* c_this
    # ... (your existing LexJ code, but replace Python string handling with calls to c_this methods)

    def __cinit__(self, source, tab_size=4):
        self.c_this = w32str.W32Str_NewUtf8(source.encode('utf-8'))
        if self.c_this == NULL:
            raise MemoryError("Failed to allocate W32Str")

    def __deinit__(self):
        if self.c_this != NULL:
            w32str.W32Str_Dealloc(self.c_this)
            self.c_this = NULL

    def get_length(self):
        return w32str.W32Str_getLength(self.c_this)

    def append(self, str):
        w32str.W32Str_AppendStr(self.c_this, w32str.W32Str_NewUtf8(str.encode('utf-8')))
```

### setup.py (Build Script)
To build the Cython module:

```python
from setuptools import Extension, setup
from Cython.Build import cythonize

extensions = [
    Extension(
        "w32str",
        sources=["w32str.pyx", "W32Str.c", "W32Str_object.c", "W32Str_json.c"],  # Add your C files
        libraries=[],  # Add libw32str.a if separate
        include_dirs=["."],  # Path to headers
        extra_compile_args=["-O3"],  # Optimization
    )
]

setup(
    ext_modules=cythonize(extensions, language_level="3"),
)
```

Run `python setup.py build_ext --inplace` to build. Then import in Python: `from w32str import LexJ`.

### Notes
- **Internals Hidden**: The `PyToken` wrapper exposes methods like your Objective-C style, keeping internals hidden.
- **Memory Management**: Use `__cinit__` and `__dealloc__` to manage C memory.
- **Parsing Methods**: Adapt `Lex_ParseNumber`, `Lex_ParseChrCon` by declaring them in .pxd and calling from .pyx.
- **Testing**: Test the wrapper with your `hjson_lexj_test.py` to ensure C methods work in Python.
